# CryptoSniper Stage23 — React Live UI

این نسخه رابط فارسی RTL تأییدشده را به رابط اصلی CryptoSniper تبدیل می‌کند و بک‌اند Django موجود را حفظ می‌کند.

## امکانات متصل‌شده به داده واقعی

- داشبورد چندصرافی، USDT آزاد، ارزش دارایی‌های قیمت‌گذاری‌شده، سفارش‌های واقعی و اعلان‌ها
- جدول یکپارچه سفارش‌های CryptoSniper و Order/Fillهای مشاهده‌شده در خود صرافی
- معامله دستی با بازارهای همان حساب، Quote زنده، TP1/TP2/TP3/SL، درصد فاصله و Fix Loss
- برنامه‌های معامله: ایجاد، ویرایش و تأیید بدون ارسال خودکار سفارش
- Smart Paste و Inbox واقعی
- صرافی‌ها: اتصال، Sync، Diagnostics، حذف اتصال و گردش کلید رمزنگاری داخلی
- Watchlist و Favorite Assetهای سراسری
- Telegram: اتصال حساب، کد/2FA، کشف کانال، آرشیو از اولین پیام قابل دسترس، توقف/ادامه آرشیو، جست‌وجو، آمار کانال و انتقال پیام به Smart Paste
- Alerts/Notifications، Reports، Operations، Profile/Preferences/Security
- Wallet Center برای Public Address / Browser Wallet بدون Seed و Private Key

## تصمیم Stage23 درباره محیط اجرا

رابط اصلی فقط حساب واقعی را می‌پذیرد. اتصال جدید Simulator/Binance در رابط Stage23 ارائه نمی‌شود. مسیرهای قدیمی محیط تمرینی به صفحه معاملات جدید هدایت یا با 410 بسته می‌شوند؛ داده‌های قدیمی برای سازگاری دیتابیس حذف نمی‌شوند.

## سفارش واقعی

ارسال سفارش Spot واقعی همچنان Fail-Closed است و تنها در صورت تمام شرایط زیر ممکن است:

- `LIVE_TRADING_ENABLED=true`
- حساب Live و Connected
- Read + Spot Trade تأییدشده
- `can_withdraw = false`
- Step-up authentication معتبر
- تأیید صریح ریسک در فرم
- بازار متعلق به همان صرافی و قیود Tick/Lot/Min Notional معتبر

## محدودیت مهم

Stage23 ارسال امن **ورود Spot واقعی** را متصل می‌کند، اما مدیریت کاملاً خودکار خروج واقعی TP/SL/Trailing تا زمان تکمیل و اعتبارسنجی چرخه خروج هر Adapter فعال نشده است. برنامه TP/SL ذخیره می‌شود و رابط این محدودیت را صریح نمایش می‌دهد. Margin live borrow/repay نیز در این نسخه اجرا نمی‌شود.

این محدودیت عمدی است تا موتور آزمایشی قدیمی به‌اشتباه به‌عنوان اجرای واقعی استفاده نشود.
