# راهنمای اتصال حساب‌های صرافی و کیف پول‌ها به CryptoSniper

نسخه: Stage 23 / React Live UI

## اصل امنیتی

CryptoSniper برای حساب صرافی فقط به کلید API با **Read + Trade** نیاز دارد. مجوز برداشت باید همیشه خاموش باشد.
برای کیف پول غیرامانی، CryptoSniper **هرگز** Seed Phrase، Mnemonic یا Private Key دریافت یا ذخیره نمی‌کند.

IP فعلی سرور CryptoSniper برای Allowlist در صرافی‌هایی که این قابلیت را دارند:

`5.61.27.185`

> اگر IP سرور در آینده عوض شد، قبل از ساخت کلید جدید، IP جدید را از مدیر سرور بگیرید.

## اتصال صرافی‌ها

| صرافی | داده لازم در CryptoSniper | مجوز لازم | برداشت | نکته |
|---|---|---|---|---|
| Bitunix | API Key + API Secret | Read + Spot Trade | OFF | در صورت امکان IP Allowlist فعال شود |
| LBank | API Key + API Secret | Read + Spot Trade | OFF | کلید دارای Withdraw توسط CryptoSniper رد می‌شود |
| Nobitex | API Token / API Key | Read + Trade طبق سطح دسترسی حساب | OFF | Adapter فعلی Secret جداگانه نیاز ندارد |
| WEEX | API Key + API Secret + Passphrase | Read + Spot Trade | OFF | Passphrase اجباری است |
| Ourbit | API Key + API Secret | Read + Spot Trade | OFF | IP Restriction در صورت پشتیبانی فعال شود |

### روند مشترک

1. در خود صرافی وارد بخش API Management شوید.
2. API جدید بسازید.
3. دسترسی مشاهده حساب/موجودی را فعال کنید.
4. فقط دسترسی معاملاتی موردنیاز را فعال کنید.
5. Withdrawal / Withdraw / Transfer-out را خاموش نگه دارید.
6. اگر صرافی IP Allowlist دارد، `5.61.27.185` را اضافه کنید.
7. در CryptoSniper به «صرافی‌ها ← افزودن اتصال» بروید.
8. کلیدها را وارد کنید و تأیید «برداشت خاموش است» را فعال کنید.
9. «ثبت و تست اتصال» را بزنید.
10. از «جزئیات و لاگ» نتیجه دقیق بررسی را ببینید.

### معنی وضعیت‌ها

- **متصل**: اعتبارسنجی انجام شده و دسترسی خواندن معتبر است؛ اگر مجوز معامله و عدم برداشت نیز تأیید شده باشد، سفارش واقعی می‌تواند با تأیید صریح کاربر ارسال شود.
- **محدود**: خواندن ممکن است کار کند ولی یکی از مجوزهای لازم برای معامله تأیید نشده است.
- **در انتظار**: بررسی Worker هنوز تمام نشده است.
- **خطا**: لاگ اتصال را باز کنید؛ کد خطا، پیام امن، آخرین زمان بررسی و وضعیت Worker نمایش داده می‌شود.
- **غیرفعال**: کلیدها لغو یا اتصال توسط کاربر متوقف شده است.

### خطاهای رایج

- Authentication failed: API Key / Secret / Passphrase اشتباه یا منقضی است.
- IP not allowed: IP سرور در Allowlist کلید نیست.
- Permission insufficient: دسترسی Read یا Trade کافی نیست.
- Withdrawal unsafe: کلید دارای مجوز برداشت است؛ کلید را در صرافی اصلاح یا دوباره بسازید.
- Worker stale: Worker مربوط به maintenance/orders/market_data فعال یا تازه نیست.
- Rate limit: تعداد درخواست‌ها از سقف صرافی عبور کرده است؛ CryptoSniper باید پس از دوره محدودیت دوباره Sync شود.

## کیف پول‌های غیرامانی

### MetaMask و کیف پول‌های EVM سازگار

در مرورگرهایی که Provider استاندارد `window.ethereum` تزریق می‌شود، CryptoSniper می‌تواند آدرس عمومی انتخاب‌شده را دریافت کند و به‌عنوان اتصال مرورگری ثبت کند.
هیچ کلید خصوصی به سرور ارسال نمی‌شود.

### Trust Wallet

اگر افزونه/مرورگر Trust Wallet یک Provider EVM سازگار در اختیار صفحه بگذارد، اتصال مرورگری مانند MetaMask انجام می‌شود. در غیر این صورت آدرس عمومی را در حالت Watch Only ثبت کنید یا WalletConnect را پس از پیکربندی Project ID استفاده کنید.

### WalletConnect

زیرساخت UI برای ثبت WalletConnect/آدرس عمومی در Stage23 وجود دارد، اما نشست کامل WalletConnect نیازمند یک **WalletConnect Project ID** معتبر و Provider کلاینت است. تا زمانی که Project ID در سرور/Build تنظیم نشده باشد، CryptoSniper آن را به‌صورت Watch Only نگه می‌دارد و نباید ادعا کند تراکنش امضاشده ایجاد می‌کند.

### Ledger و Trezor

CryptoSniper Seed یا Private Key سخت‌افزار را نمی‌گیرد. Ledger/Trezor باید از طریق یک کیف پول مرورگری سازگار متصل شود و فقط آدرس عمومی/امضای مالکیت در اختیار CryptoSniper قرار گیرد.

### EVM Address و TRON Address

برای پایش و ثبت مالکیت می‌توانید آدرس عمومی را اضافه کنید. این حالت به‌تنهایی مجوز برداشت یا امضای تراکنش نمی‌دهد.

## نکته مهم درباره معامله

اتصال کیف پول شخصی با اتصال حساب صرافی متفاوت است. برای معامله در Bitunix/LBank/Nobitex/WEEX/Ourbit باید همان حساب صرافی از طریق API متصل باشد. کیف پول شخصی در Stage23 برای ثبت/مشاهده اتصال و توسعه بعدی پایش On-chain است و به‌صورت خودکار جایگزین API صرافی نمی‌شود.

## چه چیزی را هرگز وارد نکنید؟

- Seed Phrase / عبارت بازیابی
- Private Key
- فایل Keystore به همراه رمز آن
- API Key دارای مجوز برداشت
- رمز عبور اصلی صرافی

اگر هر صفحه‌ای چنین اطلاعاتی خواست، عملیات را متوقف کنید.
