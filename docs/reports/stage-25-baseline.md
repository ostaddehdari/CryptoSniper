1. `README.md` کد آزمایشی را `0.23.0rc1` می‌نامد؛ `pyproject.toml` نسخه `0.24.0rc2` را ثبت کرده است. `docs/roadmap.md` و `docs/plan.json` تا S23 می‌رسند؛ [گزارش S24](https://github.com/ostaddehdari/CryptoSniper/blob/8c0352ddb5b5cd8639208dbd95b2e790a0746104/docs/reports/stage-24-rebuild.md) بازسازی UI را جداگانه توصیف می‌کند. بنابراین عدد نسخه در README و پیشرفت ماشینی هنوز با گزارش S24 همسان نشده‌اند.
2. `progress.json` در S23 پنج Work را گزارش می‌کند ولی وضعیت آن `partial` است؛ دو check مربوط به CI exact-source و بسته release `pending` مانده‌اند. [گزارش S23](https://github.com/ostaddehdari/CryptoSniper/blob/8c0352ddb5b5cd8639208dbd95b2e790a0746104/docs/reports/stage-23.md) credential واقعی، آزمون معامله provider و پذیرش VPS را ادعا نمی‌کند.
3. گزارش S24، Workspace راست‌چین، نمودار زنده و Card/Table را ذکر می‌کند و می‌گوید Live write همچنان پشت feature gate خاموش است. وجود فایل تست به معنی PASS شدن آن روی این SHA یا پذیرش عمومی سایت نیست.
4. استقرار فعلی در `https://srun.ir/cryptosniper` و سرور `5.61.27.185:2233` طبق اعلام مالک در مرکز مدیریت ثبت شده است؛ این ممیزی هیچ اتصال SSH، health check زنده یا مقایسه نسخه نصب‌شده با SHA منبع انجام نداده است.
