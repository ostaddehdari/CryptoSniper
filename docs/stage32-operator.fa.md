# راهنمای سیگنال و تلگرام استیج ۳۲

## اتصال امن Telegram

در صفحهٔ Telegram، API ID، API Hash و شماره را وارد و «درخواست کد» را بزنید. کد ورود و رمز 2FA فقط برای همان درخواست استفاده می‌شوند و ذخیره نمی‌شوند؛ session و credential اتصال به‌شکل رمزنگاری‌شده و خصوصی نگهداری می‌شوند. اگر کد منقضی شد از «ارسال دوباره کد» استفاده کنید. FloodWait تا زمان مجاز بعدی نمایش داده می‌شود و نباید با تلاش سریع دور زده شود.

پس از اتصال، کانال را از فهرست حساب اضافه کنید. شروع دوبارهٔ آرشیو از cursor ذخیره‌شده ادامه می‌دهد و پیام تکراری نمی‌سازد. پیام‌های تاریخی فقط برای Inbox/تحلیل/آمار هستند و هیچ معامله‌ای از backfill ساخته نمی‌شود. قطع اتصال session ذخیره‌شده را باطل می‌کند.

## Smart Paste و Inbox

Smart Paste باید علاوه بر confidence، وضعیت «کامل/مسدود» را نشان دهد. قبل از تأیید، نماد، Entry، Stop و Targets را بررسی کنید. متن مبهم یا دادهٔ ناقص قابل انتقال به معامله نیست. در Inbox می‌توانید موردها را تکی یا گروهی بایگانی، حذف نرم و بازیابی کنید. «تأیید و انتقال به معامله» فقط یک snapshot تأییدشده می‌سازد و همان مقادیر را بدون حدس به فرم دستی می‌فرستد.

## Template، AI و Hybrid

- Template: فقط قواعد نسخه‌دار همان کانال.
- AI: فقط provider تنظیم‌شده روی سرور؛ خروجی باید schema سخت‌گیرانه را پاس کند.
- Hybrid: ابتدا Template و سپس fallback کنترل‌شدهٔ AI طبق سیاست کانال.

کلید AI را در UI، git یا لاگ وارد نکنید. متغیرهای سرور `TELEGRAM_AI_BASE_URL`، `TELEGRAM_AI_API_KEY` و `TELEGRAM_AI_MODEL` هستند و پس از تغییر، سرویس‌های web/signals/telegram باید به‌صورت کنترل‌شده restart شوند. خطای provider یا خروجی نامعتبر باید خوانا بماند و سیگنال را قابل سفارش نکند.

Full-Auto در این صفحه فقط Paper است. این گزینه به سفارش Live وصل نیست. نصب Stage32 نیز `LIVE_TRADING_ENABLED` یا `LIVE_EXIT_MANAGEMENT_ENABLED` را فعال نمی‌کند.

## ارزیابی و محدودیت نتیجه

«شروع/ادامه ارزیابی» کندل تاریخی مرجع را برای سیگنال‌های قابل‌سنجش پردازش می‌کند. منبع و بازهٔ کندل در evidence نگهداری می‌شود. چون OHLC ترتیب رخدادهای داخل کندل را نشان نمی‌دهد، برخورد هم‌زمان TP و SL `ambiguous` است و نه سود قطعی و نه برد در نرخ موفقیت. no-entryهای قدیمی پس از بازهٔ نگهداری expire و بایگانی می‌شوند.

برای پذیرش واقعی، یک حساب Telegram مجاز، یک کانال مجاز و در صورت نیاز provider AI با محدودیت هزینه ارائه کنید؛ سپس نتیجهٔ code/2FA، restart آرشیو، dedup و schema provider جداگانه ثبت شود.
