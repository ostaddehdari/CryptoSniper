# راهنمای اپراتور و تحویل Stage33

## نصب یک‌خطی

پس از انتشار Release رسمی، اسکریپت pin‌شده را اجرا کنید:

```bash
curl -fsSL https://raw.githubusercontent.com/ostaddehdari/CryptoSniper/stage33-final-acceptance/scripts/deploy.sh -o /tmp/cryptosniper-deploy.sh && sudo bash /tmp/cryptosniper-deploy.sh
```

این مسیر SHA256 بسته و installer را پیش از اجرا بررسی می‌کند، از داده و تنظیمات خصوصی نسخهٔ نصب‌شده پشتیبان می‌گیرد و Live را خودکار روشن نمی‌کند.

## کنترل پس از نصب

1. خروجی باید `INSTALL_OK` و `DEPLOY_OK` داشته باشد.
2. در «وضعیت سیستم»، workerها، آمادگی استقرار و پذیرش Stage33 را بررسی کنید.
3. در «صرافی‌ها» زمان دریافت موجودی و USDT آزاد را با یک حساب مجاز صرافی مقایسه کنید.
4. در «گزارش‌ها» فقط رسیدهای واقعی نمایش داده می‌شوند؛ کارمزد مفقود باید «نامشخص» باشد، نه صفر.
5. login و صفحات نمای کلی، معاملات، صرافی‌ها، گزارش و تنظیمات را در موبایل و دسکتاپ باز کنید.
6. backup رمزنگاری‌شده بسازید و restore را فقط روی دیتابیس جداگانه اجرا کنید.

## Rollback و بازیابی

installer پیش از جایگزینی برنامه، release قبلی و dump پیش از migration را نگه می‌دارد. اگر نصب شکست بخورد، trap نصب‌کننده فایل برنامه و unitهای قبلی را برمی‌گرداند و release ناموفق را برای بررسی نگه می‌دارد. rollback دستی یا restore دیتابیس را بدون نگهداری لاگ و تأیید مقصد جدا اجرا نکنید.

## محدودیت‌های واقعی

- معامله با پول واقعی مجوز جدا می‌خواهد؛ دو switch سرور و تأیید هر معامله جای مجوز مالک را نمی‌گیرند.
- Full-Auto تلگرام فقط Simulator/Paper است و پیام تاریخی معامله نمی‌سازد.
- Futures پشتیبانی نمی‌شود.
- Telegram، AI و مقایسه موجودی واقعی بدون credential مجاز پذیرفته‌شده محسوب نمی‌شوند.
- سود خالص فقط با fill و fee دقیق قابل محاسبه است؛ مقدار ناقص «نامشخص» می‌ماند.
- ادغام شاخه در `main` جزو این نصب نیست مگر مالک جداگانه درخواست کند.

Secretها را در چت، git یا runlog قرار ندهید. کلید صرافی باید بدون Withdrawal و ترجیحاً با IP allowlist باشد.
