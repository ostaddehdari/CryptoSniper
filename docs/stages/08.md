# استیج 08 — موتور معامله، سفارش و Position

شناسه: `S08` | وضعیت اولیه: `not_started` | پیش‌نیاز: S07 کامل

## ورک‌ها

| شناسه | کار | تحویل مشخص | معیار بررسی |
|---|---|---|---|
| S08-W01 | State machine و رویدادها | lifecycle معامله و order/position مستقل؛ TP_REACHED و TRAILING_ACTIVE به‌صورت event/substate بدون تداخل fill state. | transition غیرمجاز رد و هر تغییر معتبر با trade_events افزایشی ثبت شود. |
| S08-W02 | Order intent و idempotency | trades/orders/order_fills/positions، client_order_id پایدار، outbox و uniquenessهای account-scoped. | retry API/Worker و crash بعد submit سفارش دوم ایجاد نکند؛ timeout وضعیت نامعلوم بسازد. |

## تعریف پایان استیج

تمام پنج ورک پیاده‌سازی شده‌اند؛ migration، API، UI و Worker لازم همان استیج به هم وصل‌اند؛ بررسی‌های مرتبط پاس شده و شواهد واقعی در `docs/reports/stage-08.md` ثبت شده‌اند. تغییرات با پیام فارسی و ذکر شناسه ورک‌ها کامیت و به GitHub ارسال شده‌اند. نتیجه commit و branch نهایی بررسی شده است.

اگر credentials، provider، هاست یا دسترسی خارجی لازم موجود نباشد، کار مستقل ادامه می‌یابد و بخش وابسته `blocked` یا `partial` می‌ماند. تست mock جای آزمایش واقعی provider را نمی‌گیرد. کل استیج بدون پنج ورک کامل `done` نمی‌شود.
