# استیج 11 — پردازش پس‌زمینه، بازیابی و تطبیق

شناسه: `S11` | وضعیت اولیه: `not_started` | پیش‌نیاز: S10 کامل

## ورک‌ها

| شناسه | کار | تحویل مشخص | معیار بررسی |
|---|---|---|---|
| S11-W01 | تفکیک صف‌ها و Scheduler | signals/orders/market_data/trailing/alerts/reports/maintenance؛ قرارداد queue تلگرام فقط برای استیج آخر. | گزارش سنگین صف orders را متوقف نکند و Beat در یک instance مسئول اجرا باشد. |
| S11-W02 | Locks و transaction/outbox | DB row locks برای وضعیت مالی، Redis lease با fencing/version و commit-before-dispatch. | expire شدن lock و رقابت دو Worker سبب دو submit یا close نشود. |
| S11-W03 | Retry طبقه‌بندی‌شده | backoff، jitter، timeout و dead-letter؛ سفارش نامعلوم پیش از retry از exchange lookup شود. | پس از timeout-with-order-created سفارش مجدد ساخته نشود؛ خطای دائمی retry نامحدود نشود. |
| S11-W04 | Reconciliation و recovery | order/position/balance/trade reconciliation؛ pause اجرای جدید در اختلاف حساس و recovery پس از crash. | fill گمشده و سفارش خارجی شناخته‌شده با audit بازیابی و اختلاف ناشناخته هشدار دهد. |
| S11-W05 | Health و عملیات | worker heartbeat، queue age، feed lag، last sync، کنترل pause/resume و runbook خرابی. | قطع Redis/DB/Worker آزمایش و محدودیت واقعی بازیابی گزارش شود؛ برنامه به مرورگر متکی نباشد. |

## تعریف پایان استیج

تمام پنج ورک پیاده‌سازی شده‌اند؛ migration، API، UI و Worker لازم همان استیج به هم وصل‌اند؛ بررسی‌های مرتبط پاس شده و شواهد واقعی در `docs/reports/stage-11.md` ثبت شده‌اند. تغییرات با پیام فارسی و ذکر شناسه ورک‌ها کامیت و به GitHub ارسال شده‌اند. نتیجه commit و branch نهایی بررسی شده است.

اگر credentials، provider، هاست یا دسترسی خارجی لازم موجود نباشد، کار مستقل ادامه می‌یابد و بخش وابسته `blocked` یا `partial` می‌ماند. تست mock جای آزمایش واقعی provider را نمی‌گیرد. کل استیج بدون پنج ورک کامل `done` نمی‌شود.

## دستور اجرای یک‌باره

> استیج 11 CryptoSniper را با همه ورک‌هایش طبق برنامه مخزن کامل بساز، تست‌های مرتبط را اجرا کن و در GitHub کامیت و push کن.

اجرای این دستور فقط همین استیج را شامل می‌شود؛ به استیج بعد خودکار نرو. پیش‌نیاز ناقص ابتدا گزارش شود و استیج وابسته به‌دروغ شروع/تکمیل‌شده اعلام نشود.
