# استیج 13 — Dashboard و پایش حساب

شناسه: `S13` | وضعیت اولیه: `not_started` | پیش‌نیاز: S12 کامل

## ورک‌ها

| شناسه | کار | تحویل مشخص | معیار بررسی |
|---|---|---|---|
| S13-W01 | Aggregation موجودی | total/available balance و valuation با نرخ و زمان معلوم؛ جلوگیری از جمع ارزهای متفاوت بدون تبدیل. | موجودی Spot/Margin و locked balance دوباره شمرده نشود. |
| S13-W02 | شاخص‌های معاملاتی | open trades، امروز، active signals، realized/unrealized P/L و win rate با تعریف مشترک گزارش. | شاخص‌ها با fills/fees و timezone کاربر تطبیق داشته باشند. |
| S13-W03 | رابط مستقل موبایل | نمای روشن روزمره، اقدامات یک‌دستی و اولویت قیمت/P&L/status و اعلان‌های مهم. | Dashboard در عرض موبایل فاقد scroll افقی و داده کلیدی قابل خواندن باشد. |
| S13-W04 | Workspace دسکتاپ | navigation، top bar، پنل وضعیت exchange و recent trades/signals/alerts با تراکم مناسب. | فیلتر و لینک هر کارت به جزئیات واقعی وصل باشد؛ داده ساختگی production نمایش داده نشود. |
| S13-W05 | Reactivity و کارایی | refresh جزئی، skeleton/empty/error state و جلوگیری از stale display. | قطع realtime با وضعیت واضح و reconnect صحیح؛ query count/latency اندازه‌گیری و ثبت شود. |

## تعریف پایان استیج

تمام پنج ورک پیاده‌سازی شده‌اند؛ migration، API، UI و Worker لازم همان استیج به هم وصل‌اند؛ بررسی‌های مرتبط پاس شده و شواهد واقعی در `docs/reports/stage-13.md` ثبت شده‌اند. تغییرات با پیام فارسی و ذکر شناسه ورک‌ها کامیت و به GitHub ارسال شده‌اند. نتیجه commit و branch نهایی بررسی شده است.

اگر credentials، provider، هاست یا دسترسی خارجی لازم موجود نباشد، کار مستقل ادامه می‌یابد و بخش وابسته `blocked` یا `partial` می‌ماند. تست mock جای آزمایش واقعی provider را نمی‌گیرد. کل استیج بدون پنج ورک کامل `done` نمی‌شود.
