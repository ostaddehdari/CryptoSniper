## تعریف پایان استیج

تمام پنج ورک پیاده‌سازی شده‌اند؛ migration، API، UI و Worker لازم همان استیج به هم وصل‌اند؛ بررسی‌های مرتبط پاس شده و شواهد واقعی در `docs/reports/stage-15.md` ثبت شده‌اند. تغییرات با پیام فارسی و ذکر شناسه ورک‌ها کامیت و به GitHub ارسال شده‌اند. نتیجه commit و branch نهایی بررسی شده است.

اگر credentials، provider، هاست یا دسترسی خارجی لازم موجود نباشد، کار مستقل ادامه می‌یابد و بخش وابسته `blocked` یا `partial` می‌ماند. تست mock جای آزمایش واقعی provider را نمی‌گیرد. کل استیج بدون پنج ورک کامل `done` نمی‌شود.

## دستور اجرای یک‌باره

> استیج 15 CryptoSniper را با همه ورک‌هایش طبق برنامه مخزن کامل بساز، تست‌های مرتبط را اجرا کن و در GitHub کامیت و push کن.

اجرای این دستور فقط همین استیج را شامل می‌شود؛ به استیج بعد خودکار نرو. پیش‌نیاز ناقص ابتدا گزارش شود و استیج وابسته به‌دروغ شروع/تکمیل‌شده اعلام نشود.
