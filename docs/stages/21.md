## مرزهای اجرایی

- Full-Auto کانال فقط به Simulator Paper محدود است و از مرز risk/state/executor عبور نمی‌کند.
- پنج adapter بازار، ticker/orderbook، موجودی و سفارش Spot را نرمال می‌کنند؛ `max_leverage=1` و Futures/Perpetual و Margin واقعی غیرفعال‌اند.
- سفارش Limit Spot در outbox با request key و client order ID پایدار ثبت می‌شود. مجوز provider بلافاصله پیش از write دوباره بررسی می‌شود و timeout پس از submit به `uncertain` می‌رود، نه retry.
- `LIVE_TRADING_ENABLED=false` پیش‌فرض نصب است. فقط حساب Live متصل با `can_trade_spot=true` و `can_withdraw=false` قابل صف‌گذاری است.
- جایی که API صرافی permission قابل اتکا برنمی‌گرداند، تأیید اپراتور برای کلید Read+Spot بدون Withdrawal و IP allowlist لازم است.
