# استیج ۲۳ — تثبیت معامله و UI عملیاتی

این استیج اصلاحی بر پایه بازخورد استفاده واقعی از S22 است و هیچ قابلیت قبلی را حذف نمی‌کند.

## S23-W01 — معامله دستی و Trailing
- انتخاب Coin/Pair از نتیجه جست‌وجو باید مقدار واقعی market را ثبت کند.
- Entry در معامله تازه خالی است و draft قدیمی آن را پر نمی‌کند.
- مبلغ پیش‌فرض، درصدهای TP و فاصله Trailing در UI عدد صحیح‌اند.
- نام‌ها دقیقاً Trailing و Trailing SL هستند.
- Trailing SL: پس از تکمیل TP1 فقط یک‌بار SL به Entry منتقل می‌شود.
- Trailing: Trigger قابل انتخاب TP1/TP2/TP3، پیش‌فرض TP1.

## S23-W02 — External Trade
- فهرست و جزئیات شامل symbol، side، Entry، amount، status و زمان دقیق است.
- سفارش/تاریخچه تکمیل‌شده هم قابل مشاهده است.
- مدیریت خودکار فقط با adoption صریح کاربر، حجم باقی‌مانده تأییدشده و Live Spot gate امن فعال می‌شود.
- از روی یک Fill هیچ Position باقی‌مانده‌ای حدس زده نمی‌شود.

## S23-W03 — Signal Inbox و Analytics
- Trash از نوع Soft Delete با بازیابی و عملیات گروهی است.
- Reject/Delete از جریان اصلی UI حذف شده است.
- Parsed Signal با «تأیید و انتقال به معامله» وارد فرم Manual می‌شود.
- Analytics پوشش ارزیابی، result breakdown، ambiguity و کیفیت Parser را جدا نشان می‌دهد.

## S23-W04 — Exchange و Live order reliability
- خطای ذخیره/Broker در Add Exchange به صفحه سفید تبدیل نمی‌شود.
- Disable/Revoked در Center/API/System active connections دیده نمی‌شود.
- مرز Live Spot دوباره permission، precision، limits و balance freshness را بررسی می‌کند.
- Pending order پایدار است و dispatcher دوره‌ای پس از بازیابی Broker آن را ادامه می‌دهد.
- نتیجه نامعلوم provider هرگز خودکار دوباره submit نمی‌شود.

## S23-W05 — تحویل تجمعی
- نسخه: 0.23.0rc1
- CI و Release فقط exact-source.
- ZIP، installer، SHA256 و runlog تولید می‌شوند.
- Live trading به‌صورت پیش‌فرض خاموش و provider/VPS acceptance مستقل باقی می‌ماند.
