# استیج ۲۳ — رابط React فارسی و مرکز کنترل واقعی

این استیج ظاهر تأییدشدهٔ Cornix-inspired را به سایت اصلی منتقل می‌کند و مسیرهای Django موجود را حفظ می‌کند.

## ورک‌ها
1. **S23-W01:** پوسته React RTL، سایدبار جمع‌شونده و ناوبری اصلی.
2. **S23-W02:** داشبورد داده واقعی، موجودی چندصرافی، معاملات داخلی و External Trade.
3. **S23-W03:** Manual با فیلتر بازار حساب، قیمت زنده، TP/SL درصدی، Fix Loss و Smart Paste.
4. **S23-W04:** جدول صرافی‌ها، حذف Paper/Demo از UI اصلی، connection log و راهنمای اتصال پنج صرافی.
5. **S23-W05:** اولویت ارزها با drag/drop، جست‌وجوی پیام‌های Telegram و Copy→Smart Paste، تست/CI.

## مرزهای ایمنی
- حذف Paper/Demo از رابط به معنی دورزدن safety gateهای سرور نیست.
- Fix Loss فقط **عدد پیشنهادی** تولید می‌کند و سفارش ایجاد نمی‌کند.
- External Trade تا زمان واگذاری صریح کنترل فقط خواندنی است.
- API Key/Secret/Passphrase هرگز در پاسخ API یا لاگ اتصال بازنمایش داده نمی‌شود.
- راهنمای اتصال مربوط به حساب‌های صرافی پشتیبانی‌شده است؛ اتصال کیف پول self-custody/on-chain در این استیج ادعا نمی‌شود.

## پذیرش
کد پنج ورک کامل است اما Stage23 تا پاس CI دقیق و نصب/پذیرش عمومی روی VPS در وضعیت `partial` باقی می‌ماند.
