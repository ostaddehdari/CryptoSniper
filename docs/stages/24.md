# استیج ۲۴ — چارت زنده، نمایش سیگنال و بایگانی معاملات

این استیج بازخورد استفاده واقعی از Workspace را به یک مسیر رسمی و قابل استقرار در GitHub تبدیل می‌کند.

## S24-W01 — چارت کندلی زنده
- API خصوصی چارت برای بازارهای قابل‌خواندن کاربر.
- بازه‌های 1m، 5m، 15m، 1h، 4h و 1d.
- استفاده از OHLC نرمال‌شده و polling سبک برای Workspace.
- New Trade فقط بازار انتخاب‌شده را نشان می‌دهد و خطوط معامله باز قبلی را overlay نمی‌کند.

## S24-W02 — سطوح و رویدادهای سیگنال/معامله
- Entry، TP1، TP2، TP3 و SL به‌صورت خط قیمت افقی.
- زمان برخورد به هر سطح با خط عمودی و نقطه دایره‌ای رنگی روی کندل متناظر.
- رنگ‌ها: Entry آبی، TPها سبز، SL قرمز، Expired نارنجی و External بنفش.
- Trade Detail برای Paper و External overlay اختصاصی دارد.

## S24-W03 — Workspace رسمی /app/
- مسیرهای hash: `#/inbox`، `#/newtrade` و `#/trades`.
- Inbox دارای Card/Table، شماتیک کوچک کارت و شماتیک کامل Detail است.
- Workspace از فایل‌های versioned داخل Repository ارائه می‌شود؛ UI دیگر نباید یک لایه ناشناخته خارج از Git باشد.

## S24-W04 — Archive و Refresh
- «حذف» معامله به معنای Archive است، نه حذف رکورد.
- Active / Archive / All برای Signals و Trades.
- Signal با Outcome=Expired به‌صورت دوره‌ای archive می‌شود.
- Unified Trades شامل Paper داخلی، Live order داخلی و External observation است.
- Refresh معاملات یک read-sync واقعی روی حساب‌های متصل اجرا می‌کند و سپس لیست تازه را برمی‌گرداند.

## S24-W05 — تست و تحویل
- نسخه 0.24.0rc1.
- Migrationهای archive برای Signals، Trades، LiveSpotOrder و ExternalObservation.
- تست‌های Workspace، auto archive، unified trades، refresh boundary و chart overlay.
- Live write همچنان feature-gated و پیش‌فرض خاموش است.
