# استیج 29: بازگردانی رابط اصلی React و تحویل نصب معتبر

تاریخ برنامه: ۲۶ اکتبر ۲۰۲۶. این سند بخشی از برنامه پایانی پنج‌استیجی است.

## S29-W01: ادغام مبنای React و ثبت برنامه پایانی

خروجی: حفظ Backend و migrationهای main، ادغام React Stage25 و قفل styles.css تأییدشده.

پذیرش: صفحات اصلی از root React استفاده کنند؛ migrationهای قدیمی حذف یا بازنویسی نشوند.

## S29-W02: تثبیت پوسته و ناوبری نهایی

خروجی: سایدبار خلوت، هدر تتر، مسیرهای قدیمی سازگار، دکمه معامله جدید و خروج درست.

پذیرش: ناوبری و خروج در مرورگر واقعی کار کند؛ مسیر ناشناخته صفحه سفید نسازد.

## S29-W03: دارایی‌های نسخه‌دار و PWA امن

خروجی: Build قابل نصب بدون Node سرور، آدرس‌های مستقل از پیشوند، cache نسخه‌دار و محافظت Offline.

پذیرش: نسخه جدید bundle با cache قدیمی جایگزین نشود؛ درخواست مالی در Offline ارسال نشود.

## S29-W04: آزمون یکپارچه و پذیرش رابط

خروجی: Build، schema، PostgreSQL، API و مرورگر در عرض‌های 320،390،768،1440.

پذیرش: خروجی واقعی تست و تصاویر ثبت شود؛ ظاهر پایه حفظ و overflow افقی نداشته باشد.

## S29-W05: Release و نصب‌کننده React

خروجی: Release از همان SHA موفق CI، ZIP تجمیعی، SHA256، installer --check و deploy.sh پین‌شده.

پذیرش: بسته منتشرشده شامل React ساخته‌شده باشد؛ نصب داده و secrets قبلی را حفظ کند.

نبود credential یا دسترسی سرور مانع بخش مستقل نیست؛ پذیرش واقعی بدون شواهد ثبت نمی‌شود.
