# CryptoSniper React UI

نمونه‌ی فرانت‌اند RTL و فارسی برای CryptoSniper با ظاهر الهام‌گرفته از Cornix و سایدبار جمع‌شونده.

## اجرا

```bash
npm install
npm run dev
```

## صفحات پیاده‌سازی‌شده
- نمای کلی با ویجت‌ها، جدول موجودی و تب‌ها
- معاملات یکپارچه و External Trade
- معامله دستی با قیمت زنده نمایشی، TP/SL درصدی و Fix Loss
- Smart Paste / تحلیل سیگنال
- صرافی‌ها به‌صورت جدول و لاگ اتصال
- دیده‌بان و ارزهای اولویت‌دار
- تلگرام و جست‌وجوی پیام‌ها
- تنظیمات اعشار و نمایش

> داده‌ها در این نسخه Mock هستند و برای اتصال به API فعلی CryptoSniper باید endpointها به سرویس‌های واقعی متصل شوند.
